GOOD QUESTIONS

A little more context.

Is this website the CRM application?

This is the static product and documentation site. The CRM runs separately with a Next.js web app, an Express API, and MySQL. The hosting guide explains both deployment paths.

Can I edit records directly in spreadsheet cells?

The table enhancement supports navigation, range selection, copying, resizing, and density controls. Record updates still use the application’s existing editing flows; these tables are not a formula engine.

Does every dashboard number follow the fiscal period?

Period-based metrics use the selected reporting period. Lifetime totals and stored relationship statuses retain their own meaning. Check each label before comparing values.

Is OyamaCRM open source?

The repository is private and access follows its GitHub permissions. Review LICENSE.md for terms before using or distributing the application.

Are these screenshots live organization data?

No. They are captures of the application using synthetic QA records. They demonstrate the interface and do not establish production readiness for every module.
