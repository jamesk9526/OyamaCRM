# Donor workspace unification — October 30, 2026

Unify Dashboard, Constituents, and Donations around clear daily workflows without removing advanced tools.

- Shared workspace links and visual hierarchy; contextual links preserve the supporter and gift scope.
- Consistent search, quick views, advanced filters, result summaries, selection tools, and pagination.
- Display full filtered-dataset metrics with clear denominators. Keep stored donor status distinct from actual period giving.
- Reduce row action noise while retaining editing, templates, stewardship automation, merging, and deletion behind existing review/permission paths.
- Improve dashboard focus, cross-page handoffs, and progressive disclosure of detailed analysis and tools.
- Validate with focused unit/API tests, production build, and isolated browser fixtures at desktop and mobile sizes. No deployment, outbound communications, or live record writes.
